§ 01 Abstract

Programmatic dynamic visual artifacts — animations, simulations and interactive visualizations — are specified by executable programs, which makes them parametric, controllable and reproducible. In practice, coding agents are often tasked with editing these artifacts given only a rendered video and an underspecified instruction that states the primary modification while leaving its structural, quantitative and temporal consequences implicit.

We formulate this task as video-conditioned programmatic editing from undescribed instructions: without access to the original source code, an agent must reconstruct the underlying scene, execute the explicit edit, propagate its implicit consequences over time, and preserve all unaffected content and dynamics.

VEDIT-Bench comprises 678 editing tasks across 226 source scenes spanning seven domains and three program families, organized into three escalating tiers — L1 local edits, L2 linked updates and L3 rule or structural changes — and paired with time-anchored Direct Derived Invariant metrics. Evaluating eight frontier coding agents reveals that while local edits barely differentiate models, performance degrades sharply on L3, accompanied by a substantial rank reshuffle and a pronounced drop in dependent updates.

§ 02 The task

One sentence, many consequences.

Given only a source video and an instruction with hidden intent, an agent must rebuild the scene as code, apply the edit, and carry its unstated effects through time.

01

Agents get the pixels

The agent receives a rendered clip — here, an HTML/JS atom viewer showing calcium. The program that produced it is withheld, so structure, layout and orbital dynamics must be recovered from frames alone.

02

…and one undescribed editing instruction.

The video-editing instruction names the primary change and nothing else. Turning Ca into Ca2+ silently implies two fewer orbiting electrons, a new configuration, a different valence, and an emptied outer shell throughout the animation.

03

The agent infers and writes a program.

Without source code or frame reuse, the agent must synthesize a standalone program that reconstructs and re-renders the edited video from scratch.

04

Three obligations, scored apart.

The rendered video is judged against a hidden reference edit, criterion by criterion:

    § 03 Three levels
    
      
    L1- L3 editing levels.
    
      
    Every source video is edited at three levels that hold reconstruction difficulty fixed while widening the scope of causal propagation.
    
    
    
    
    
      
    
        L1
        
        
    Local edit
    
        
    Alters a single label, visual attribute or isolated state. Nothing else should move.
    
        
    “Make the electrons orbiting the calcium nucleus green.”Chemistry · calcium atom
    
      
    
      
    
        L2
        
        
    Linked update
    
        
    Alters an element together with directly linked ones — a value, its visual encoding and the summary readout.
    
        
    “Record one more night delivery that took 18 minutes.”Charts · delivery histogram
    
      
    
      
    
        L3
        
        
    Rule or structure change
    
        
    Alters a governing rule, threshold or structural relation, so later states must be re-derived over time.
    
        
    “Make the rightmost gear slide out of mesh while the gears turn, then slide back.”Physics · three-gear chain

    § 05 How we score
    
      
    Evaluation.
    
      
    Holistic video similarity misses small but decisive changes — a single numeric label can flip correctness while touching a few pixels. So every task carries observable, time-anchored criteria, rated 0–4 by a VLM judge that inspects source, reference and candidate frame by frame.
    
    
    
    
    
      
    
        
        
    Direct
    
        
    Did the named change happen — at the right moment?
    
        
    Verifies the explicitly requested object, attribute or state change at the specified time.
    
        
    Three-gear chain, L3: the rightmost gear slides out of mesh, then back in.
    
      
    
      
    
        
        
    Derived
    
        
    Did the unstated consequences follow?
    
        
    Verifies that rule-governed effects nobody spelled out propagate consistently over time.
    
        
    Same task: the detached gear’s pointer halts while out of mesh, then resumes — opposite to the middle gear.
    
      
    
      
    
        
        
    Invariant
    
        
    Did everything else stay put?
    
        
    Verifies that unrelated objects, layouts, styles and motion patterns are not disturbed.
    
        
    Same task: the two independent gears keep their teeth, colours and rotation.
    
      
    
    
    
    
    
      
    
        
        
    Fidelity
    
        
    Preservation of the source outside the edit region, weighted towards lines, text and edges.
    
      
    
      
    
        
        
    Smoothness
    
        
    Motion dynamics against the reference: freezes, bursts, flicker, pacing and duration.
    
      
    
      
    
        
        
    GT improvement
    
        
    Share of the source→reference gap closed inside the edit region: 0 = unchanged, 100 = reference.
